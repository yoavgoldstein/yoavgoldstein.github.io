# Yoav Goldstein — minimal academic website

Design inspired by the one-page academic structure at https://canishknaik.github.io/.

## Publishing

Upload `index.html`, `styles.css`, `portrait.jpg`, `research.html`, and `cv.pdf` to the root of your GitHub Pages repository. `research.html` is an optional redirect for older links.

The site includes three working papers, one work-in-progress project, and two publications. The biography describes research in labor economics and behavioral economics. The contact email is yoavgolds@berkeley.edu.
